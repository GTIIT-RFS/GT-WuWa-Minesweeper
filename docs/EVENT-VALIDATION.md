## 发现后修复的问题

- 恢复时旧 HTTP 测试仍返回字符串身份，与新匿名身份对象契约不一致；已修正。
- 数据库复合行在无当前轮次时转 JSON 会得到全 null 的对象；现显式返回 JSON null，避免结束后出现虚假当前轮次。
- 私人领奖 fragment 在站内切页时被父路由提前清除；现在由后台读取后清除，桌面与手机回归通过。
- 揭晓测试曾点击被自动揭晓层覆盖的刷新按钮，等动画结束后才点击成功。现直接验证自动轮询发现结算，再检查揭晓与下一轮，定向桌面／手机各重复 3 次全部通过，最终整套 32 项也通过。

最终没有仍然失败的本地必需检查。负向构建的 exit 1 是预期拒绝，不是未修复的生产构建失败。
