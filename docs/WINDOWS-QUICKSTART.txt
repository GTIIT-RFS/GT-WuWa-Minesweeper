GT WuWa · 扫雷，但是爆的是土豆 — Windows 离线试玩版

1. 将 ZIP 完整解压到任意普通文件夹，不要在压缩包内直接运行。
2. 双击 Potato-Minesweeper.exe。程序会启动本机服务器并打开默认浏览器。
3. 若浏览器没自动打开，输入 http://127.0.0.1:4173/
4. 保持程序的黑色窗口打开；关闭窗口或按 Ctrl+C 会停止服务。

无需安装 Node.js、Python、Go 或其他运行时，也不需要管理员权限。
需要 Windows 10/11 和现代 Edge / Chrome 浏览器；建议首次使用最新浏览器。
普通 Intel/AMD 64 位电脑选 amd64 包，Windows ARM 电脑选 arm64 包。
EXE 包含游戏页面、图片、CSS 和 JavaScript，无需下载额外资源。
这是未做商业代码签名的自制程序，Windows 可能提示未知发布者。

管理员设置 → 素材管理：上传土豆图片、爆炸主图、背景、社团 Logo 等。
管理员设置 → 特效编辑器：选择动画预设或测试爆炸。
排行榜、图片、配置保存在当前浏览器的本机网站数据里；换电脑不自动同步。
请始终用同一浏览器与同一地址（127.0.0.1:4173）保留记录，不要使用隐私模式。
上传素材不要删掉原始备份；配置 JSON 导出不包含素材和成绩。

同一时间只运行一份程序。如端口被占用，请关闭上一份程序。
也可在命令行执行 Potato-Minesweeper.exe --port 4174 选择其他端口；
换端口会切换到独立的网站存储，因此原来的图片与成绩不会显示。
服务仅绑定本机，其他电脑或手机不能直接连进来。跨设备试玩请使用网站部署。
不要直接双击构建目录的 index.html。

构建者验证：源码构建、Windows amd64/arm64 交叉编译、同源 Linux 服务器及真实浏览器测试。
限制：当前开发环境不是 Windows，尚未在真实 Windows 系统执行 EXE；活动前请在现场电脑验收。
