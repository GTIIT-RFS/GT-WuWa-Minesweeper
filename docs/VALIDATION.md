## 调试和边界

最初构建发现空 CSS import 解析失败，已移除并重建成功。Playwright 官方浏览器下载被环境网络策略拒绝，随后改用环境自带 `/usr/bin/chromium` 完成全部交互测试，没有关闭 TLS 或校验，也不需要新增网络放行。依赖重装使用 npm 完整性校验。

本次不是 Safari / Firefox 或真实 iPad 的验证，也不是数小时稳定性或内存分析。建议活动前在现场设备验证触屏、声音、全屏和大图片性能。音频文件编码兼容性、浏览器配额及全屏权限由设备决定。
